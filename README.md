# 工厂劳保鞋尺码发放与到期换领系统

管理员工代号、岗位防护等级、脚型尺码、鞋款、库存批次、试穿结果、发放日期、使用期限、
损坏申请、旧鞋回收与例外换领。纯 Python 标准库实现（`http.server` + `sqlite3`），零第三方依赖。

## 一条本地启动命令

```bash
./run.sh            # 准备演示样例 + 自检 + 启动，浏览器打开 http://127.0.0.1:8000
./run.sh 9000       # 指定端口
python3 -m shoe_system --reseed   # 等价的模块方式
```

启动命令会重置并写入三个重点样例：

| 样例 | 员工 | 场景 |
|---|---|---|
| 缺码候补 | E1004 孙安全 | GUARD-SB 41 码两仓无货，已排队；库存矩阵给 41 码入库后自动提醒 |
| 跨岗位调动 | E1006 吴进步 | 冲压 S1 → 铸造 S3（主管办理），调岗换领单待领取 |
| 提前换领 | E1005 周大勇 | 鞋底/鞋头/鞋帮三张磨损照片，待主管审批，可勾选旧鞋遗失豁免 |

另含：E1003 已逾期、E1001 30 天内到期；一双鞋待清洁复检、一双报废鞋待处置。

界面右上角可切换 **仓管·刘库 / 主管·陈厂 / 管理员** 三种角色体验权限差异。

## 业务规则

- **岗位授权 → 可领规格**：鞋款挂防护等级；员工只能试穿/发放本等级授权鞋款。
- **试穿锁码**：最近一条试穿结果为“合适”才锁定尺码并允许发放；“需调码/不合脚”使锁定失效。
- **左右脚差异**：档案分记左右脚 EUR，发放码不得小于较大脚，发放单记录 `L42/R41`。
- **唯一有效鞋**：`issuances` 上有部分唯一索引
  `(employee_id, grade_code) WHERE status='active'`，同一员工同一等级只能有一双有效鞋；
  两处仓库并发发放时整笔 `BEGIN IMMEDIATE` 事务串行，**仅一次成功**。
- **库存原子扣减**：条件更新 `… WHERE qty_used<qty_total`，最后一双不会超扣；
  缺码自动登记/复用候补单，到货后进程内任务生成提醒。
- **期限计算**：到期日 = 发放日 + 等级期限（月），月末日期钳制（1/31 + 1 月 = 2/28）。
- **换领前置**：正常到期单到期后自动可换；提前磨损必须三照片且主管审批。
- **交旧才能领新**：领取时旧鞋 `reusable` → 清洁复检（不合格再转报废），
  `scrap` → 待处置批次；旧鞋遗失须主管审批时授予豁免并登记原因，否则无法领取。
- **角色权限**：主管/admin 才能审批提前换领、办理跨岗位调动；仓管发放/入库/复检，
  **不能修改岗位等级**，越权操作返回 400 并写审计日志。
- **处置回执**：待处置批次出厂时由模拟厂商适配器出具回执号 `RC-XXXXXXXXXX`。
- **门禁工号**：模拟门禁/HR 适配器按员工代号同步 `BD-XXXXXXXX` 工号并模拟刷卡核验。

## 目录结构

```
shoe_system/
  db.py          SQLite 表结构（含部分唯一索引）与连接
  services.py    全部事务化业务规则
  adapters.py    门禁工号 / 处置厂商 模拟适配器
  reminders.py   进程内提醒线程（到期 + 候补到货，60 秒）
  seed.py        演示数据与占位磨损照片（纯标准库生成 PNG）
  server.py      HTTP：JSON API + multipart 照片上传 + 静态托管
  __main__.py    启动入口
web/             前端（原生 HTML/CSS/JS，无构建）
tests/test_services.py  19 个 unittest
data/shoes.db    SQLite 发放链路（运行时生成）
data/photos/     磨损照片本地目录
```

## 测试

```bash
python3 -m unittest tests.test_services -v
```

覆盖：有效鞋唯一、两处仓库并发发放仅一次成功、最后一双原子竞争、期限月末计算、
试穿调码失效、左右脚差码、缺码候补与到货提醒、提前换领三照片与主管审批、
旧鞋遗失豁免、交旧分流（复检/处置）与回执、重复领取拦截、仓管岗位权限。

## 界面

工业白 `#f4f6f9` + 钢蓝 `#1f4e79` + 荧光黄 `#e3ee2a`。库存按鞋款分块、尺码成二维矩阵，
格内直接显示剩余总量与 `A:x / B:y` 分仓余量；员工页突出防护等级色块与当前鞋款；
磨损审核固定鞋底/鞋头/鞋帮三个照片位；矩阵与所有区块采用 auto-fit 网格 +
`overflow-x:hidden`，窄屏自动重排，不出现横向滚动。
